# ⚔️ Kanto League

🔗 **Demo:** https://kanto-league.infinityfreeapp.com/?i=1

Aplicación web de batallas Pokémon y Pokédex, desarrollada como proyecto de la carrera de Diseño y Programación Web en Escuela Da Vinci.

## ✨ Características
- Batallas entre Pokémon
- Pokédex para explorar los Pokémon

## 🛠️ Tecnologías
PHP · HTML5 · CSS3 · [JavaScript]
